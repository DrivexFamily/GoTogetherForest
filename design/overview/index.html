같이가숲 개발 지도

아이는 "언제 도착해?"라고 묻는 대신 화면 속 길을 따라가는 우리 차를 봅니다. 아빠가 부드럽게 운전한 거리만큼 아이 계정의 숲에 나무가 자라고, 보호자에게는 포인트가 쌓입니다.

0% 만화 여섯 편 보면 도착해요

주차 중: 진행 바는 1%씩 움직이고, 캐릭터 애니메이션이 함께 나옵니다.

위 장면은 실제 앱 화면이 아니라 개념 그림입니다. 주행 중을 누르면 앱이 실제로 지킬 규칙대로 캐릭터가 멈추고, 진행 바는 전환 효과 없이 1%씩 이동합니다(실제 앱은 최소 15초 간격). 길 위의 깃발은 10%마다 있는 이정표입니다.

핵심 가치와 타깃

진행 화면이 주인공, 숲은 다시 오게 만드는 이유

심사 기준 네 가지(차량 특화성, 창의성, 기술 활용성, 사업성)에 각 기능이 어떻게 답하는지 정리했습니다.

문제

"아빠, 언제 도착해?"

긴 이동에서 아이는 시간 감각이 없어 같은 질문을 반복하고, 운전자는 대답하느라 주의가 흩어집니다. 목적지에서 기다리는 가족도 "어디쯤이야?"를 묻습니다.

    숲과 포인트 계산

    부드럽게 달린 거리만큼 숲이 자랍니다

    모든 차종에 같은 기준을 씁니다. 급가속·급출발·급감속·급정지가 있었던 1km만 빼고 나머지 거리를 인정합니다. 친환경차는 생애 배출이 적은 만큼 아이 숲에 보너스 새싹을 받습니다. 속도나 도착 시간은 보상하지 않고, 주행 중에는 판정 결과를 알리지 않습니다.

    위험운전판정 기준 (1초마다 차속 변화)
    급가속21km/h를 넘는 속도에서 초당 +8km/h 이상
    급출발5km/h 이하에서 초당 +10km/h 이상
    급감속6km/h 이상에서 초당 −14km/h 이상
    급정지초당 −14km/h 이상 줄어 5km/h 이하로

    한국교통안전공단 위험운전행동 기준 중 승용차에 가장 가까운 택시 기준입니다. 연속된 이벤트는 1건으로 묶고, 이벤트가 있던 1km만 빼서 필요한 제동을 꺼리지 않게 합니다. 차속은 AAOS CarPropertyManager에서 읽습니다.

    숲과 동물

    아이 계정에 쌓이는 숲, 나무가 늘면 친구가 찾아와요

    숲은 아이 프로필에 계속 쌓입니다. 누적 나무가 늘면 다람쥐, 토끼, 새가 하나씩 찾아옵니다. 아래 해금 기준은 예시이며 2차에서 구체화합니다. 동물 소리는 주차 중에만 짧게 한 번 납니다.

    계정과 포인트

    숲은 아이 것, 포인트는 보호자 것

    만 14세 미만은 보호자 동의가 필요하므로 보호자 계정 아래에 아이 프로필을 둡니다. 아이가 여럿 함께 타면 모두 같은 나무를 받고, 포인트는 여행마다 한 번만 보호자에게 쌓입니다. 로그인과 프로필 만들기는 주차 중에만 엽니다.

    코드 구조

    두 기능은 서로 모르고, 같은 이벤트만 듣습니다

    진행 화면(feature:journey)과 숲(feature:forest)은 서로를 직접 부르지 않고 core:trip이 보내는 이벤트만 구독합니다. 그래서 한쪽만 켜도 앱이 동작합니다. 위쪽 스위치로 데이터 출처를 바꿔 보세요. 주행 제한 신호는 어떤 모드에서도 끄지 않습니다.

    app얇은 껍데기. 화면 이동, 의존성 조립(수동 DI), 기능 켜기/끄기만 맡습니다.
    core:vehicleVehicleDataProvider(읽기)와 VehicleControlProvider(제어, 지금은 빈 구현). SDK 래퍼가 모두 여기 있습니다.
    core:demo시간축에 따라 진행률·도착 이벤트(비상 시 차속까지)를 같은 인터페이스로 흘려보내는 데모 재생기.
    core:trip출발, 진행률, 주행/정차, 도착을 이벤트로 발행합니다. 차속으로 위험운전을 판정해 인정 거리(안전 km)도 계산합니다.
    core:account보호자 계정과 아이 프로필, 포인트 지갑. 지금은 기기 저장(Local)이고 PT부터 서버(Remote)로 바꿔 끼웁니다.
    core:ui테마(라이트·다크), Asta Sans 글꼴, SVG 레이어 캐릭터 컴포넌트.
    feature:journey진행 화면, 남은 시간 환산, 도착 화면, (PT) 공유 링크 생성.
    feature:forest안전 km 기반 새싹·나무, 아이 이름의 숲, 동물 해금과 소리, 결과 화면.
    server · web(PT 단계) Cloudflare Workers + KV 공유 서버와 수신자용 웹 화면.

    미리 알고 있는 걸림돌

    높음DO(주행 중 사용) 선언 방법과 Kids 카테고리의 주행 중 허용 범위가 문서에 없음운영 측에 문의. 답이 없거나 불허면 매니페스트만 바꿔 주차 전용 앱으로 후퇴(코드는 그대로)
    높음에뮬레이터가 Apple GPU(M5)에서 잘 도는지 미확인11/2 첫 부팅을 가장 먼저. 안 되면 바로 다른 PC 확보 상의. 녹화는 전원 연결, 장면별로 나눠서
    중간NaviHelper 필드명·단위·호출 빈도 미확인, 내장 내비가 이벤트를 주는지 미확인데모 모드가 시연을 책임지고, 확인되면 진행률을 실데이터로 전환
    중간'창밖동화'(2026 플레오스 커넥트 고객 아이디어 공모 대상, 위치 기반 AI 동화)와 랜드마크 기능이 겹칠 수 있음우리 핵심(내비 진행률, 에너지 기반 숲)은 겹치지 않음. 랜드마크는 시안으로만 두고 운영국 답변에 따라 결정
    중간아동 정보와 위치 정보의 개인정보 부담별명만, 기기에만 저장(Keystore 암호화). 공유는 진행률 기본, 대략 위치는 옵트인
    중간포인트를 실제 현대차 구매권으로 바꾸려면 제휴가 필요앱에서는 "제휴 시 · 예시"로 표시하고 기획서에는 블루멤버스 연동을 사업 제안으로 넣음. 선례: 서울시 에코마일리지 × 현대차·기아
    중간급제동 판정 때문에 필요한 제동을 꺼리게 될 위험이벤트가 있던 1km만 빼고, 주행 중에는 알리지 않으며, 도착 후에는 칭찬만 함
    낮음심사 기준의 "더미 데이터 금지"와 데모 모드의 충돌메뉴에서 명시적으로 켜고, 켜져 있는 동안 "데모 주행" 배지를 항상 표시
    낮음블라인드 원칙: 현재 저장소 소유자 계정이 드러남중립 GitHub 조직을 만들고 제출 직전 작성자를 정리한 히스토리로 이전
