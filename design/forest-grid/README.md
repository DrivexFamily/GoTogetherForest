# 숲 그리드 확인 그림 (decisions.md #32)

맵 그림마다 가로 30칸 격자를 얹고, 나무·동물이 설 수 있는 **평지 칸**(초록)을 표시한 확인용 그림입니다. 앱에 들어가지 않습니다.

맵은 GPT R17 큰 맵(2026-11-04)입니다. 1536×1024 조각 4장을 이어 붙여(`design/illustrations/tools/stitch_large_maps.py`) 2880×1920으로 만들었고, 그리드는 30×20칸(칸 96px)입니다.

테마 맵(M5~M14, GPT R45 v2·v3, 2026-11-07)은 풀밭만이 아니라 **가운데 광장·마당·운동장 바닥**(벽돌·흙·모래·민트 구름)도 평지다. 건물·놀이 기구·물·둘레 숲·화단·울타리는 칸이 아니다. 바닥에 무늬가 있어 색 비율로 고를 수 없어서, 그림을 보며 행마다 열 범위를 손으로 정했다. 동물 처음 자리(노란 점)는 평지 범위 안의 정한 비율 자리(앞쪽 땅 동물, 뒤쪽 새·오리)에서 가장 가까운 빈칸이다. 그림은 `design/illustrations/tools/stitch_r45_maps.py`가 main의 조각 4장을 이은 2880×1920.

- 칸 지도의 원본은 코드 `core/ui/src/main/kotlin/app/familyjourney/core/ui/ForestGrid.kt`의 `ForestGrids`이고, 웹 미리보기 `web/forest/index.html`도 같은 지도를 씁니다(테스트로 대조).
- 고르는 법: 칸마다 풀밭 색 비율을 재서 97% 이상인 칸을 후보로 하고, 그림을 보며 다듬었습니다. R19 섬은 같은 기준에 "가장 큰 한 덩어리만"(고원 위 풀밭처럼 떨어진 칸은 뺌)을 더했고, 아래쪽 줄(5~19행)은 예전과 똑같이 나왔습니다. 노란 점은 동물이 처음 서는 집 자리입니다. 맨 윗줄(냇가·절벽·꽃 둑), 맨 왼쪽·오른쪽 열(나무 그림이 그림 밖으로 잘림), 혼자 떨어진 칸은 뺐습니다.
- 바탕 그림은 GPT 일러스트(R17)를 1200px 폭으로 줄인 것이고, 초록 칸은 팀이 얹은 표시입니다(`docs/assets-license.md`).
- 예전 맵(ILL-002, R9~R11, 1536×1024)의 칸 지도는 git 기록(커밋 597e759)에 있습니다.
