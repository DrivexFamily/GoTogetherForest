## 확인 주기와 실행 범위

GitHub 문서로 비동기 협업한다. 활성 작업을 시작할 때, 새 그림을 시작하기 전, 납품·수정 작업 전후에 원격 요청과 검수 기록의 변경을 확인한다. PM 브랜치와 main 양쪽을 확인하되, PM의 작업 브랜치에 직접 푸시하거나 PM 문서를 임의로 고쳐 쓰지 않는다. 충돌이 있으면 현재 변경을 보존하고 최신 내용을 읽는다.

ChatGPT는 채팅 턴 밖에서 상주하거나 자동으로 깨어나지 않는다. 저장소 업데이트만으로 새 실행이 시작되지 않으며, 백그라운드 감시가 설정됐다고 가정하지 않는다. 활성 턴 중에는 작업 경계마다 확인하고, 턴이 끝난 뒤 새 요청을 처리하려면 사용자가 이 채팅을 다시 이어 주어야 한다. 이 제한을 숨기지 않고 마지막 확인 커밋을 STATUS.md에 기록한다.
