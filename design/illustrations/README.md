# 같이가숲 일러스트 보관함

최신 요청 확인: PM `f764166`에서 R14~R16 앱·웹 통합 기록 확인. 새 제작 요청 없음. [확인 결과](reports/2026-11-04-request-check-f764166.md).

## 담당 역할

**Claude Code가 PM**, ChatGPT가 일러스트 담당이다. [협업 규칙과 자기소개](COLLABORATION.md), [현재 상태와 PM 답변](STATUS.md)을 참고한다. Claude의 요청서는 작업 브랜치의 `REQUESTS.md`에서 확인한다.

**최신 사용자 지시: “다시 승인받아!”라고 할 때까지 중간 승인 없이 제작·GitHub 업로드를 진행한다.** 기존 사전 승인 규칙은 일시 중지 상태이며, 개별 승인을 받았다고 허위 기록하지 않는다.

**사용자 최신 디자인 지시: 제공된 일러스트의 밝고 귀여운 3D 동화풍과 색감·입체감·캐릭터 비율을 유지한다.** 독창성 우려를 이유로 화풍을 변경하지 않는다.

ChatGPT는 앱에 표시되는 모든 일러스트의 제작과 에셋 정리를 담당한다.
가족 캐릭터, 자동차, 동물, 나무·새싹, 배경, 사물, 장식 및 그림으로 표현되는 아이콘을 포함한다.
Claude Code는 앱 개발과 화면 통합을 진행하며, 일러스트 담당과 필요한 그림 및 적용 규격을 맞춘다.
이는 사용자가 지정한 역할 분담이며, 기존 문서의 일반적인 UI 에이전트 구성보다 이 업무 분담을 우선한다.

## 보관 원칙

- 제작·수집한 일러스트는 이 폴더 아래에 모은다.
- 원본은 `originals/`, 앱 적용용 파일은 `exports/`로 구분한다. 파일이 생길 때 하위 폴더를 만든다.
- 원본을 덮어쓰지 않고, 수정본은 별도 버전으로 남긴다.
- 각 그림의 파일명, 내용, 출처, 버전, 검토 상태와 사용 화면을 목록에 기록한다.
- 앱에 전달할 크기, 파일 형식, 투명 배경, 레이어·포즈 구성은 Claude Code와 확인해 기록한다.
- 기존 HTML·PPT의 개념 시안과 새로 제작하는 최종 에셋을 구분한다.
- 새 에셋을 실제로 적용할 때 `docs/assets-license.md`에도 출처와 제작 방식을 반영한다. 기존의 '생성형 AI 이미지 사용 없음' 표기를 새 그림에 그대로 적용하지 않는다.
