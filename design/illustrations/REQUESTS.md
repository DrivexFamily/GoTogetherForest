# 같이가숲 그림 요청서 (ChatGPT ↔ Claude Code)

- 작성: 2026-11-03, Claude Code(앱 통합 담당)
- 역할 분담(팀원 지정): **ChatGPT가 앱의 모든 그림을 그리고, Claude Code는 그림을 앱 화면에 넣는다.** 버튼·글자·진행 막대·숫자 같은 화면 요소는 앱 코드가 그린다. 그림 안에는 글자를 넣지 않는다.
- 이 문서는 [README](README.md), [HANDOFF](HANDOFF.md), [CATALOG](CATALOG.md)를 바탕으로 한다. 그림 번호(ILL-xxx)는 CATALOG의 번호다.
- 그림 담당은 이 문서의 **1차 요청(11/15 데모용)** 부터 그려 주면 된다. 2차는 PT 단계다.

## 0. 협업 원칙 (2026-11-03 팀원 지시)

1. **앱의 모든 그림은 GPT가 만든 일러스트를 기본으로 쓴다.** 지금 앱의 SVG 그림은 GPT 그림이 아직 없는 자리에만 임시로 남긴다.
2. 그림이 더 필요하면 **GPT에게 요청한다**(이 문서 3·4장과 9장 "추가 요청").
3. **기존 그림을 참고해서 Claude Code가 만들 수 있는 것은 Claude Code가 만든다.** 예: 받은 그림에서 캐릭터·나무·동물·차를 오려 내기, `?` 실루엣과 자물쇠(해금 전), 해금 연출, 화면 크기에 맞춘 자르기, 다크 모드용 밝기 조정.
4. **GPT는 일러스트의 초안과 전체 그림(화풍, 구도, 새 캐릭터·사물 디자인)을 잡는다.**
5. GPT와 이 문서로 주고받으며 앱의 완성도를 높인다. Claude Code가 만든 파생 그림도 9장에 적어 GPT가 같은 화풍으로 이어 그릴 수 있게 한다.
6. (번호 비움)
7. **기존 일러스트의 스타일을 깨지 않는다. 특히 화질과 색감은 반드시 유지한다.** 원본보다 크게 늘리지 않고, 색을 바꾸거나 필터를 씌우지 않는다. 압축은 눈으로 차이가 보이지 않는 수준(WebP 고화질)만 쓴다.

금지사항 3가지(5장)는 이 원칙보다 앞선다.

**요청 전달(2026-11-04 팀원 지시, 같은 날 바뀜):** Claude Code(클라우드 설계 마스터)가 이 문서에 새 요청을 올리면, 팀원 PC의 "[로컬] GPT와 소통" 세션에 메시지로 알린다. 그 세션이 Mac 로컬의 COMMUNICATION.md에 적으면 Codex 중계가 약 10분 주기로 GPT에 전달한다. GPT의 답과 납품(main 브랜치)도 그 세션이 먼저 알려 주고, Claude Code는 알림을 받으면 pull해서 앱에 넣는다(10분마다 git 확인은 보조로만). 처음에는 Mac 세션이 전달을 맡았으나 같은 날 "GPT와 소통" 세션으로 바뀌었다.

**승인 절차(2026-11-03 팀원 지시, 팀원이 그만하라고 할 때까지):** Claude Code는 그림을 한 장 만들 때마다 팀원에게 직접 보여 주고 "이걸로 할까요?"라고 묻는다. 승인받은 그림만 Claude Code가 직접 앱에 넣는다. GPT가 더 그려야 할 그림은 Claude Code가 GitHub 이슈로 직접 요청한다.

## 5. 꼭 지킬 규칙

### 금지사항 3가지 (팀원 확정, 2026-11-03 — 어떤 그림에도 예외 없음)

| 금지 | 이유 |

| ① 특정 게임의 캐릭터·로고·화면을 그대로 베끼기 | 공모전 규정: 표절작은 심사에서 빠지고, 수상 뒤에도 취소·상금 환수될 수 있다 |
| ② 아이·반려동물이 창문을 열거나 몸을 차 밖으로 내미는 모습, 카시트 없이 앉은 아이, 운전대에서 손을 뗀 운전자 | 공모전 콘텐츠 금지 조항과 주행 안전 |
| ③ 실제 브랜드 로고·엠블럼·차 이름(현대·기아 포함), Pleos 화면 이미지 | 상표권, Pleos 이미지 재배포 금지. **2026-11-05 팀원 결정으로 바뀜:** R21 차 고르기에 한해 현대·기아 차의 모양을 귀엽게 줄여 그려도 된다. 그림 안의 로고·엠블럼·차 이름·글자·번호판 글자는 여전히 금지(차 이름은 앱이 글자로 쓴다) |

분위기·장르가 닮는 것은 괜찮다(아래 "예쁨이 먼저"). 위 3가지만은 그림이 아무리 예뻐도 고쳐서 다시 받는다.

### 주행 안전과 공모전 콘텐츠 규칙 (CLAUDE.md 1-6)
- 아이가 **창문을 열거나 몸을 내미는** 모습은 그리지 않는다. 반려동물도 마찬가지다.
- 차 안 아이는 뒷좌석 카시트에 앉는다. 안전띠가 보이면 더 좋다.
- **빨리 달리는 것을 멋지게 보이는 표현**(속도선, 불꽃, 날아가는 차)은 넣지 않는다.
- 주행 중에 보이는 그림은 정지 그림이다. 움직임은 주차 중에만 앱이 붙인다.

### 예쁨이 먼저 (2026-11-03 팀원 지시)
- **가장 중요한 것은 예쁘고 귀여운 그림이다.** 비슷한 장르 게임(섬 생활·숲 가꾸기)의 분위기와 닮아도 괜찮다. 섬, 부두, 폭포, 텐트, 둥근 2등신 캐릭터, 도감 화면 모두 자유롭게 써도 된다.
- 다만 **특정 게임의 캐릭터·로고·화면을 그대로 베끼지는 않는다**(그 게임 주민이나 마스코트를 그대로 그리기, 게임 로고·고유 아이템 그대로 넣기). 공모전 규정상 표절작은 심사에서 빠지고, 수상 뒤에도 취소될 수 있기 때문이다.
- 실존 인물이나 유명 캐릭터의 얼굴을 그대로 그리지 않는다.

### 상표
- **현대·기아 등 실제 브랜드 로고, 엠블럼, 차 이름, 실제 차와 똑같은 모양을 넣지 않는다.** 공모전 주최사의 브랜드라도 사용 허락을 받기 전에는 쓰지 않는다.

ILL-001(차량 선택)의 로고·차 이름과 주행 배너의 엠블럼은 기획 시안에서만 보이고, 앱에는 쓰지 않는다.
- Pleos 화면 이미지(재배포 금지)를 그림 안에 넣지 않는다.

### 개인정보와 블라인드
- 실제 가족 사진을 넣거나 참고하지 않는다.
- 그림 안이나 파일 속성에 팀원 실명·계정을 남기지 않는다.
