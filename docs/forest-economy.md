## 1-1. 어른 안전 운전 마일리지(점) 규칙 (decisions.md #36, 2026-11-06)

아이 ★와 **따로** 센다. 보호자 것이다. 아이가 ★를 써도 마일리지는 줄지 않는다(지갑이 다르다).

| 항목 | 규칙 | 코드 |
| --- | --- | --- |
| 쌓기 | 부드럽게 달린 비율 **90% 이상**인 여행만, 부드럽게 달린 1km = 1점. 차종과 무관 | `ForestRewards.mileageFor` |
| 비율 | 판정한 구간 중 부드럽게 달린 비율(도착 결과의 "부드럽게 달린 구간 N%"와 같은 값) | `SafeDriveSummary.smoothPercent` |
| 90% 미만 | 0점("부드럽게 달린 구간이 90% 이상인 여행만 마일리지가 쌓여요"). ★는 그대로 쌓인다 | `MileageReason.BELOW_SMOOTH` |
| 여행당 | 1번만 | `TripRewardRules` |
| 월 상한 | 3,000점 | `MileageWallet.MONTHLY_CAP` |
| 데모 | 0점 | `MileageReason.DEMO` |
| 판정 못 함 | 차속을 몰랐던 거리는 세지 않는다. 판정한 구간이 없으면 0점 | `MileageReason.NOT_JUDGED` |
| 교환 | 아직 없음(예시). 화면에 "1점 = 1원 가치 · 5,000점부터 5,000원 제휴 교환 · 제휴 시 · 예시". ★에 있던 교환 줄(#7-3)을 옮겼다 | `ForestTexts.exchangeLine` |
| 저장 | 계정 JSON의 `mileage`(보유·누적·이번 달), 여행 기록의 `miles`·`milesBefore`·`milesReason`. 없는 예전 저장본은 0점으로 읽는다(예전 ★를 옮기지 않음) | `AccountCodec` |
| 화면 | 도착 결과에 ★ 카드("아이 별 ★")와 마일리지 카드("어른 안전 운전 마일리지")를 따로 | `ArrivalResultScreen` |

예: 400km 중 360km를 부드럽게(90%) → ★ +360, 마일리지 +360점. 400km 중 350km(87%) → ★ +350, 마일리지 0점.

## 5. 데모(발표용)

| 항목 | 규칙 |
| --- | --- |
| 데모 여행 | 0★. 새싹은 아이 숲에 쌓이고 기록에 "데모"(#22-⑥) |
| 발표용 ★ | 데모 모드·주차 중에 발표자 패널(진행 화면) 또는 숲 화면 아래 발표자 띠의 "발표용 ★ +1000" |
| 데모 중 해금·고르기 | 메모리의 발표용 세션에만 적는다. 저장하지 않는다 |
| 데모를 끄면 | 발표용 ★, 그것으로 연 것, 데모에서 고른 나무 종류·맵이 사라진다. 실제 ★·해금은 그대로 |
| 데모 여행의 나무 | 데모 세션에서 고른 종류로 심고, 데모를 꺼도 숲에 남는다(새싹이 남는 #22-⑥과 같음) |

시연 대본 예: 데모로 해 보기 → (휴게소 정차) 발표자 패널 펼치기 → "발표용 ★ +1000" → 도착 → 숲 보러 가기 → 나무 도감 → 소나무(500★) "열기" → 숲 맵 → 케이블카 바닷가(모은 ★ 2,000 필요 → 모자라면 "발표용 ★ +1000"을 한 번 더) → 홈으로(데모 끔) → 숲 화면에서 원래대로 돌아온 것 확인.

## 6. 숲 꾸미기 소품 가격표 (decisions.md #38, 2026-11-06)

코드 기준은 `core/account/.../DecorCatalog.kt`(가격·칸·높이), 규칙은 `DecorRules.kt`, 설계는 `docs/architecture.md` 20장. 숫자를 바꾸면 코드와 이 표를 같이 고친다.

- 아이 별(★, #36)로 산다. ★는 가족 지갑에서 빠지고, 산 소품은 **보고 있던 아이**의 보관함에 들어간다. 같은 소품을 여러 개(한 종류 99개까지) 살 수 있다.
- 가격 기준(한 달 1,000km ≈ 1,000★): 작은 소품(돌·꽃) 20~80★, 울타리·길 타일 10~30★(여러 개 사니까), 중간(벤치·등불·화단) 100~300★, 큰 것(오두막·정자·연못) 500~1,500★.
- 데모 중에는 해금처럼 발표용 세션에만 산다(데모를 끄면 사라짐).
- 칸 = 숲 맵 바닥 칸(가로×세로). 높이 = 그림 키(칸, 다 자란 나무는 2.1칸). 납작 = 길처럼 바닥에 깔아 나무·동물보다 먼저 그림.
- 그림 열의 ✅는 앱에 들어간 그림(73종). 그림이 없는 소품은 상점에 보이지 않는다(나머지 R43은 GPT 납품·총괄 PM 검수 뒤).
