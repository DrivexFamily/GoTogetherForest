   - 사이트 어디에도 심사용 GitHub 계정 이름은 게시되어 있지 않다(필요 없다고 명시).
2. **README 필수 항목이 하나 늘었다:** "개발에 사용한 Pleos Connect 에뮬레이터 버전과 화면 규격". 현재 README에는 버전(v2.1.0)은 있으나 **화면 규격(해상도 등)이 없다.**
3. **공개되지 않은 SDK는 공모전 기간에 제공되지 않는다.** "개발 문서에 공개되지 않은 SDK와 Pleos LLM SDK는 공모전 기간 중 제공되지 않습니다", "문서에서 지원되지 않는 기능은 사용할 수 없습니다. 필요한 경우 기획서에 향후 계획으로 적어 주세요". → CLAUDE.md 5-7의 "미공개 SDK(제어권)까지 제공 예정" 기대는 사실상 끝. 제어 기능은 기획서의 향후 계획으로만.
4. **'준비 중' SDK도 써도 된다:** "Pleos Playground 워크스페이스에 '준비 중'으로 표시되어 있더라도 개발 문서에 안내된 방법으로 에뮬레이터에서 개발·시험할 수 있습니다". 사용 가능 SDK는 Vehicle, NaviHelper, TextToSpeech, **SpeechToText**, FusedLocation 5종.
5. **운영사무국은 기술 질문(개별 기능 구현, 특정 API 동작)에 답하지 않는다.** → CLAUDE.md 0-1 #14의 운영 측 질문(DO 선언 방법, Kids 카테고리 주행 중 허용 범위)은 답을 기대하기 어렵다. 또한 "이번 공모전의 심사는 Pleos App Market 입점 심사가 아닙니다".
6. **접수양식 작성이 유연해졌다:** DOCX·PDF 모두 제출 가능, 전자서명(패드·마우스)과 서명 이미지 삽입 인정, 필수 항목과 순서만 지키면 글꼴·표 변경과 이미지·도표 삽입 가능, PPT·PDF·HTML 추가 자료 첨부 가능(심사 참고용), 시연 영상·첨부 분량 제한 없음, 대표자가 아닌 팀원 메일로 제출 가능(수정 제출은 처음 보낸 주소로).
