# 도감 랜드마크 좌표

`landmark-coordinates.json`은 여행 도감(결정 #40)에서 "도착하면 랜드마크를 얻는다"를 판정할 때 쓰는 기준 좌표입니다.
앱 코드(`core/atlas/.../LandmarkData.kt`)는 `design/illustrations/tools/build_landmark_assets.py`가 이 파일을 읽어 만듭니다. 손으로 고치지 않습니다.

## 출처와 라이선스

- 좌표: [Wikidata](https://www.wikidata.org/) 항목의 좌표 속성(P625). 라이선스는 CC0 1.0(퍼블릭 도메인)이라 표기 의무는 없지만 출처를 남깁니다.
- 이름·시도·시군구 분류: GPT 그림 팀 U02·U03 모형(`design/illustrations/`)
- 조회일: 2026-11-07

## 찾는 방법

1. 랜드마크 이름과 그 변형(괄호 보조명 뺀 이름, 괄호 안 이름, 띄어쓰기 없앤 이름)을 만든다.
2. 위키데이터 한국어 라벨, 그다음 별칭(altLabel)이 정확히 같은 항목 중 좌표가 있는 것을 찾는다.
3. 그 랜드마크가 속한 시·도의 범위(사각형, 여유 약 6km) 안에 있는 후보만 남긴다. 라벨로 찾은 후보를 별칭보다 먼저 쓴다.
4. 같은 이름 후보가 서로 5km 넘게 떨어져 있으면 잘못 고를 수 있어 뺀다(`dropped_ambiguous`).

## 현재 상태

- 500곳 중 253곳에 좌표가 있습니다.
- 좌표가 없는 곳은 도감에 보이지만 도착으로 얻을 수 없고, 화면에 "도착 확인 준비 중"으로 표시됩니다.
- 남은 곳은 위키데이터 이름이 달라 자동으로 맞추지 못한 곳입니다. 공공데이터(한국관광공사 관광지 좌표 등)로 채우려면 그 라이선스(공공누리 유형)를 `docs/assets-license.md`에 먼저 기록합니다.
- 도착 반경은 이름에 따라 다릅니다(산·섬·공원·해수욕장은 넓게). 기준은 생성 스크립트의 `radius_for`에 있습니다.
