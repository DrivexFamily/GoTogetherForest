# 시연 대본 (PT 현장 3분 · 시연 영상 녹화 공용)

같은 대본으로 11/13 시연 영상(Mac 녹화)과 12/3 PT 현장 시연을 합니다. 앱 동작의 근거는 `docs/architecture.md` 10-4, 준비 명령은 `README.md`.

## 준비 (시작 5분 전)

- [ ] 에뮬레이터 Cold boot, 화면은 **내비 + 같이가숲 반반**(내비는 홈 화면이어도 됨)
- [ ] `bash tools/mac/stage.sh`(문 닫힘, 기어 P, 차속 0, 무드등 흰색, 주행 규제 끄기)
- [ ] Virtual Console 열기(`adb forward tcp:8088 tcp:8088` → `http://127.0.0.1:8088/`), 기어 P
- [ ] 아이 프로필 2명(예: "하늘이", "바다" — 가상 별명), 숲 초기화 여부 결정(데모 새싹은 쌓임)
- [ ] 길 풍경: "여행마다 바꾸기" 또는 보여 줄 테마 하나(데모는 늘 첫 테마 숲길, 고르면 그 테마)
- [ ] 소리 켜짐, 노트북 음량 확인(출발·절반·감사 음성)
- [ ] 녹화라면: 에뮬레이터 창만 잘라 찍기(메뉴 막대·알림·계정 이름이 보이지 않게, 블라인드)
- [ ] 비상: Virtual Console이 안 되면 발표자 패널 "전부 데모 (비상용)"
- [ ] **배속:** 앱 데모 기본은 16×(약 10초 주행이면 도착, 결정 #41). 이 3분 대본대로 하려면 "데모로 해 보기" 뒤 발표자 패널 "펼치기" → **2×**. 짧게 보여 줄 때는 16× 그대로
- [ ] 데모를 켜면 발표용 ★ 30,000·대부분 해금으로 시작하고, 데모 도착 때 도감 절반이 함께 채워짐(축하는 목표 한 곳만)

## 잘 안 될 때

| 증상 | 바로 할 것 |
| --- | --- |
| 출발 음성이 안 남 | 계속 진행(화면 문구가 대신함). 끝난 뒤 `adb shell am force-stop ai.pleos.playground.caas` |
| VC가 안 열림·쓰기 실패 | 주차 중 발표자 패널 "전부 데모 (비상용)" 켜기 → 데모가 차속·기어까지 만듦 |
| 진행 바가 안 오름 | 기어 D이고 차속이 1km/h 이상인지(섞기 모드는 서 있으면 기다림) |
| 도감 축하가 안 나옴 | 이미 얻은 곳이면 다시 축하하지 않음(데모를 껐다 켜면 데모로 얻은 기록이 지워짐). 기어 P인지 확인 |
| 앱이 가려짐 | 다시 열면 같은 여행으로 이어짐(데모는 처음부터일 수 있음 → "처음부터") |
