## 같이가숲 광고에 옮길 것

1. **아이 1인칭 목소리(자막만):** "제 이름은 하늘이에요." "할머니 댁은 아주아주 멀어요." "그래서 자꾸 물어요. 아빠, 언제 도착해?" → "이젠 안 물어봐요. 화면 속 우리 차가 알려 주거든요."
2. **가족을 위한 어른의 마음:** 아빠는 부드럽게 운전하고(그만큼 아이 숲이 자람), 앱은 도착하면 "운전해 줘서 고마워요"와 숲 초록 무드등으로 답한다.
3. **결과가 드러나는 장면:** 도착해 주차하면 아이 숲에 나무가 서고, 지나온 랜드마크가 한 화면에 모인다.
4. **고마움으로 끝:** "아빠, 오늘도 같이 가 줘서 고마워요." → "함께 달린 길이, 아이의 숲이 됩니다." → 끝 화면(앱 이름만).
5. **Pleos 화면을 정확히:** 넓은 디스플레이에 내비 + 같이가숲 반 화면(왼쪽 운전 정보는 앱이 가리지 않음). 주행 중엔 정지 그림, 주차 중에만 움직임.
6. **자막:** 작고 조용하게(크고 두꺼운 광고 글씨 아님), 컷마다 한 문장.
7. **지킬 것:** 실제 브랜드 로고·차종·실존 인물 없음, 현대차 공식 광고처럼 보이지 않게, 안전 규칙(카시트·벨트·닫힌 창·운전자 앞보기).
