[클라우드] 기획서·발표 자료 세션이 관리합니다. 1차 결과(11/23) 뒤 이 뼈대로 슬라이드를 만듭니다.

- **가정:** 발표 10분 + 현장 에뮬레이터 시연 + 기술 Q&A. PT 시간·형식·심사 기준은 운영국 공지 뒤 맞춥니다(CLAUDE.md 1-1).
- **발표자:** 팀원(생성형 AI 사용 가능하지만 구조와 로직을 직접 설명해야 함, CLAUDE.md 1-4). 기술 Q&A 준비는 `docs/architecture.md`와 아래 "예상 질문".
- **그림:** GPT R40 PT 배경 6장(아래 표), R23 하루 이야기·기다리는 할머니, R33 계획 시안 3장(일행 모드·마일리지·사진 캐릭터). R41 앱 마켓 그림은 수상 뒤 마켓 소개용이라 PT에는 쓰지 않습니다(`docs/proposal/README.md`). 화면은 11/12 고정 빌드의 에뮬레이터 캡처.
- **원칙:** 한 장에 한 메시지. 숫자는 근거와 함께, 가정치는 "(가정)". 블라인드: 이름·소속 대신 팀명 "도토리".
- 관련 파일: [시연 대본](demo-script.md), [숏폼 대본](shorts-script.md), 기획서 원문 `docs/proposal.md`.
