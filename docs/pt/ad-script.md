# 광고 영상 대본 "함께 달린 길이, 아이의 숲이 됩니다" (60초, 가로 16:9)

## 방향

- **결:** 현대차 가족 광고처럼 큰 사건 없이 차 안의 작은 순간, 자연광, 대사보다 표정. 브랜드(앱 이름)는 끝에만.
- **메시지:** 차에서 시작한 숲이 집·학교로 이어지고, 친구들 사이에 퍼진다 → Pleos 생태계. 조르기는 부드럽게.
- **소리:** 대사 없음(자막만, 블라인드 원칙). 배경음은 직접 만든 광고용 BGM `design/audio/ggf_ad_bgm_60.mp3`(정확히 60초): 0~11초 피아노만(출발·차 화면) → 11~34초 피아노 선율과 현악(지나온 곳·도착·집에서 숲) → 34~51초 고조(친구들·우리 차엔?) → 51~60초 풀리며 끝(앱 이름).
- **만드는 법:** 고급 반실사 일러스트 정지 장면(가상 인물, 마스터 지시 11-10: "실사화하지 말고 그림체로, 퀄리티 좋게, 너무 만화 같지 않게") + 실제 앱 캡처(`design/screens/app/`)를 천천히 밀고 당기며(켄 번스) 이어 붙인다. 편집·자막·합성은 클라우드에서 `ffmpeg`로.
- **콘셉트 표시:** 아직 없는 기능(폰에서 숲 꾸미기, 친구 숲 놀러가기)이 나오는 장면 오른쪽 아래에 작은 글씨 "콘셉트 장면".

## 지킬 것

- 현대차 로고, 실제 차종 외형, 공식 광고처럼 보이는 문구를 쓰지 않는다. 차는 특정 모델이 아닌 가족 차.
- 운전 중 장면의 차 화면은 정지 그림만. 운전자는 앞을 본다. 창밖으로 몸 내밀기, 창문 열기 없음.
- 빠른 도착을 칭찬하지 않는다. "부드럽게 달린 만큼" 숲이 자란다.
- 인물은 모두 가상(실존 인물·연예인 닮은꼴 없음). 아이 이름은 가상 별명.
