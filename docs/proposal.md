## 1. 앱 한 줄 소개

**같이가숲(Go Together Forest) — 아이에게는 "언제 도착해?"의 답을, 가족에게는 함께 키운 숲을.**

내비 경로와 차량 데이터로 목적지까지 가는 길을 아이 눈높이 그림으로 보여 주고, 부드럽게 달린 거리만큼 아이의 숲에 나무를 심는 Pleos Connect 앱입니다. 지나온 랜드마크는 아이의 여행 도감에 담기고, 그 숲은 집과 친구에게로 이어집니다.

## 2. 기획 배경

- 명절·주말 가족 이동의 **88.4%가 승용차**이고, 서울→부산 귀성은 최대 **10시간 30분**이 걸립니다(2026 추석 전망, 국토교통부·한국교통연구원).
- 아이는 한 번의 차 여행에서 평균 **10번** "언제 도착해?"를 묻습니다(영국 부모 2,000명 조사, 2025).
- 이 질문은 **아이**(지루함), **운전자**(대답하느라 주의 분산), **기다리는 가족**("어디쯤이야?" 전화)을 함께 힘들게 합니다.

같이가숲은 이 답을 운전자의 말 대신 **차 화면과 짧은 음성**으로 옮기고, 이동 시간을 아이가 기다리고 싶은 시간으로 바꿉니다. Pleos Connect가 현대·기아·제네시스 전 차종으로 넓어지는 지금(2030년 약 2,000만 대 목표), 가족 고객이 차 안에서 가장 먼저 만나는 앱이 되려 합니다.

## 3. 주요 기능 및 차량 특화 요소

| 기능 | 시점 |
| --- | --- |
| A. 진행 화면(내비 목적지 확인, 풍경 길 위의 우리 차, 휴게소·도착 장면, 음성 안내) | 11/15 구현 |
| B. 아이의 숲(부드러운 운전 → 새싹·나무, 아이 별★·어른 마일리지, 숲 꾸미기, 배경 음악) | 11/15 구현 |
| C. 여행 도감(지나온 랜드마크 500곳) | 11/15 구현 |
| D. 데모 모드(서울역 → 부산역, 에뮬레이터에서 실제 동작) | 11/15 구현 |
| E. 숲 계정과 친구 숲 놀러 가기(차·폰·태블릿) | PT 단계 |

### A. 진행 화면 — "언제 도착해?"에 답하기 [11/15 구현]

- **내비 목적지 확인:** 내비에 목적지를 넣으면 같이가숲이 "목적지: 부산역이 맞습니까?"라고 묻습니다(주차 중에만 확인창, 주행 중에는 한 줄). [맞아요]를 누르면 바로 진행 화면이 열립니다.
- **풍경 길 위의 우리 차:** 진행률 = 간 거리 ÷ (간 거리 + 내비의 남은 거리). 꼬부랑 풍경 길(10가지) 위를 우리 차가 1%씩 나아가고, 길 끝에서는 토끼·다람쥐가 기다립니다. 주차 중에 길 풍경과 우리 차(현대·기아 18종)를 고릅니다.
- **멈춘 곳에 맞는 장면:** 휴게소 그림은 **기어 P + 시동 끔 + 휴게소 500m 안**일 때만 보입니다. 다른 곳에서 잠깐 멈추면 "잠깐 멈췄어요"와 지금까지 자란 새싹 수만 보입니다. 도착해 주차하면 가족이 손을 흔들고 "운전해 줘서 고마워요", 실내 무드등이 숲 초록으로 바뀝니다.
- **음성 안내:** "출발! 같이 가 볼까?", "절반 왔어요", "거의 다 왔어요", "부드럽게 달려 줘서 고마워요"(차 안에서 처리하는 Pleos 음성 합성).
- **내비 옆 반 화면:** 운전자는 내비를 그대로 보고 아이는 옆 화면을 봅니다. 좁은 창·세로 화면·라이트/다크에 맞춰 배치가 바뀌고, 앱이 꺼져도 12시간 안이면 같은 여행으로 이어 갑니다.
- **주행 중에는 정지 그림:** 주행 중에는 움직임과 버튼이 없습니다(조작 0개). 움직임·고르기·숲·도감은 주차 중에만 열립니다.

### B. 아이의 숲 — 부드럽게 달린 만큼 자라는 숲 [11/15 구현]

- **부드러운 운전의 기준(국내 기준):** 한국교통안전공단의 운행기록 위험운전행동 기준(택시) 중 4가지를 차량 차속(1초 변화량)으로 판정합니다. 이 4가지가 없던 1km 구간만 "부드럽게 달린 거리"로 셉니다.

| 위험운전 | 판정 기준(1초 동안 차속 변화) |
| --- | --- |
| 급출발 | 5km/h 이하에서 +10km/h 이상 |
| 급가속 | 21km/h 초과에서 +8km/h 이상 |
| 급감속 | −14km/h 이상(줄어든 뒤 5km/h 초과) |
| 급정지 | −14km/h 이상 줄어 5km/h 이하로 |

- **숲이 자람:** 부드럽게 달린 10km마다 새싹 1개, 새싹 10개면 나무 1그루. 전기차 ×1.5, 하이브리드 ×1.3 보너스. 주행 중에는 평가를 알리지 않고, 도착 뒤 "부드럽게 달린 360km만큼 숲이 자랐어요"처럼 칭찬만 합니다. 빨리 도착한 것은 보상하지 않습니다.
- **아이 별(★)과 어른 마일리지:** 아이는 ★로 나무 10종·동물 10종을 하나씩 열고, 보호자에게는 안전 운전 마일리지가 쌓입니다(교환은 제휴 시).
- **숲 꾸미기:** 숲 맵 14곳(낮·저녁), 나무·동물 끌어서 옮기기, 보관함, 꾸미기 상점 소품 73종. 주차 중에는 동물이 움직이고 나무가 자라며, 직접 만든 배경 음악이 작게 흐릅니다.
- **아이 정보 보호:** 첫 실행에 보호자 확인 뒤 아이 별명만 만들고, 별명은 기기 안에서 암호화(Keystore)해 저장합니다.

### C. 여행 도감 — 지나온 곳을 모으기 [11/15 구현]

- 전국 17개 시·도, 랜드마크 500곳(GPT 그림). 차가 랜드마크 **500m 안을 지나가면** 담기고, 주행 중에는 배지 그림만 조용히 보입니다. **주차하면** [받기]로 도감에 넣고, 도착하면 "랜드마크 5곳을 획득했어요!"를 한 화면에서 함께 축하합니다.
- 위치는 판정에만 쓰고 이동 경로는 저장하지 않습니다. 판정 좌표는 위키데이터(CC0) 253곳부터 시작해 넓혀 갑니다.

### D. 데모 모드 — 심사 에뮬레이터에서 실제로 동작 [11/15 구현]

- 데모는 **동영상이 아니라 앱이 실제로 동작하는 모드**입니다. 가상 내비가 "서울역 → 부산역"(약 400km) 경로를 주고, 진행률·랜드마크·도착은 실제 여행과 **같은 코드**(진행률 계산, 안전 운전 판정, 도감 판정, 숲 적립)를 거칩니다.
- Pleos Connect 에뮬레이터에서는 Virtual Console의 **기어·차속·주행 제한이 실제 신호로 들어가**, 기어 D면 주행 중 정지 화면, P면 확인창·축하·숲이 열립니다. 발표자가 급하게 가속하면 그 구간은 부드러운 운전에서 빠집니다.
- 발표를 위해 16배속으로 재생합니다. **실제 차라면 데모 여행이 도착하려면 실제로 약 10초를 달려야 합니다**(시속 60km면 약 170m, 시속 100km면 약 280m). 차가 서 있으면 데모 여행도 멈춰 기다립니다.
- 데모 중에는 "데모 주행" 배지를 항상 보이고, ★ 30,000과 대부분 열린 숲으로 기능을 바로 보여 준 뒤, **데모를 끄면 모두 사라집니다**(실제 아이 숲·도감은 그대로, 포인트·마일리지는 쌓이지 않음).

### E. 숲 계정과 친구 숲 놀러 가기 [PT 단계]

- **숲은 계정에 저장됩니다.** 보호자 계정 아래 아이 프로필마다 숲(심은 나무, 배치, 도감, ★)이 서버에 저장되어, 차를 바꾸거나 다른 기기에서 열어도 그대로 이어집니다. 11/15 앱은 차 안에 저장하고, PT 전까지 서버 저장으로 옮깁니다.
- **어디서나 같은 숲:** 같은 숲을 **Pleos 차 화면**(주차 중)과 **안드로이드 스마트폰·태블릿 앱**에서 봅니다. 폰·태블릿에서는 언제든 숲을 보고 꾸밀 수 있고(동승자·집), 차 화면에는 다음 정차 때 반영됩니다(주행 중 그림이 갑자기 바뀌지 않게).
- **친구 숲에 놀러 가기:** 보호자끼리 초대 코드(또는 QR)로 "숲 친구"를 맺으면, 아이들은 서로의 숲에 놀러 가 둘러보고 발자국·스티커를 남깁니다. 차에서는 주차 중에만, 폰·태블릿에서는 언제든.
- **아이를 지키는 원칙:** 친구 맺기는 양쪽 보호자가 모두 승인해야 하고 언제든 끊을 수 있습니다. 친구에게 보이는 것은 아이 별명과 숲 모습뿐이며 위치·주행 기록·사진은 공유하지 않습니다. 자유 대화(글자 입력)는 없고 정해진 스티커만 씁니다.
- **기대:** 차에서 키운 숲이 집과 친구 사이로 이어져, 같은 플랫폼의 차를 타는 가족들이 하나의 숲으로 연결됩니다.

### F. 가족 폰 앱과 진행 공유 링크 [PT 단계]

- **가족 폰 앱(안드로이드):** 주차 중 차 화면의 QR을 폰으로 찍어 가족을 연결합니다(비밀번호 없이 1회용 코드, 기기마다 보호자 승인). 첫 화면·QR 연결·진행 보기·숲 보기 화면은 만들어 두었고(기본 꺼짐), PT 전까지 차와의 동기화를 켭니다.
- **진행 공유 링크:** 목적지에서 기다리는 가족이 앱 설치 없이 웹에서 "하늘이네 차 62%, 약 48분"을 봅니다. 정확한 좌표는 보내지 않고, 대략 위치는 보호자가 주차 중에 켤 때만 약 5km 칸으로 뭉개 보냅니다. 도착하거나 24시간이 지나면 서버에서 지웁니다.

### G. 확장 계획

- **캐릭터 꾸미기:** 2등신 가족 캐릭터의 머리 모양·옷·차 색(주차 중·폰에서).
- **마일리지 교환:** 보호자의 안전 운전 마일리지를 충전·정비·차량 구매 혜택과 연결(제휴 시, 블루멤버스 연동 제안).
- **지나갈 때 음성 설명:** "오른쪽에 남산서울타워가 보여요"처럼 보기만 유도하는 짧은 설명(창문 열기·몸 내밀기 유도 없음).

### 차량 특화 요소 — 모바일 앱이 아니라 차량 앱이어야 하는 이유

| 항목 | 같이가숲이 쓰는 차량 기능 |
| --- | --- |
| 진행률 | 차 내비 경로·남은 거리 그대로, 목적지를 앱이 먼저 확인(NaviHelper) |
| 운전 중 안전 | 주행 제한 신호로 화면 자동 전환(CarUxRestrictions) |
| 정차·휴게소 판단 | 기어·주차브레이크·시동 상태(CarPropertyManager) + 내비 현재 위치 |
| 부드러운 운전 | 차량 차속으로 급출발·급가속·급감속·급정지 판정, 거리는 누적 주행거리(Vehicle SDK) |
| 알림 | 차 스피커 음성(TextToSpeech), 도착 축하 실내 무드등(Vehicle SDK 제어) |
| 여행 기록 | 내비 위치로 지나온 랜드마크 자동 판정(NaviHelper) |
| 화면 | 내비 옆 반 화면(운전 정보를 가리지 않음), 와이드 화면 조수석 쪽 창 |

### 주행 안전 설계

- 주행 중: 정지 그림과 1% 단계 갱신(최소 15초 간격)만, 터치할 것 없음, 전체화면 팝업 없음.
- 주차(기어 P·주차브레이크)를 확인한 뒤에만: 확인창, 움직임, 숲·도감·꾸미기·고르기, 데모 시작, 배경 음악.
- 콘텐츠 원칙: 창밖은 "보기"만 유도, 빠른 도착 보상 없음, 광고·게임 요소 없음. 데모 중에도 실제 주행 제한이 켜지면 제한 화면이 우선입니다.

## 4. 주요 사용 시나리오 — 할머니 댁 가는 날

1. **집 주차장:** 아빠가 내비에 할머니 댁을 넣자 같이가숲이 "목적지: 할머니 댁이 맞습니까?"라고 묻고, [맞아요]. 하늘이(7세)가 벚꽃길 풍경과 우리 차를 고릅니다. "출발! 같이 가 볼까?"
2. **고속도로:** 화면에는 멈춘 그림과 벚꽃길 위의 우리 차, 길 끝에서 기다리는 토끼. 하늘이는 묻는 대신 화면을 봅니다. 독립기념관 근처를 지나자 위 칸에 배지가 조용히 뜹니다.
3. **휴게소:** 시동을 끄고 P에 두자 휴게소 장면으로 바뀌고, 하늘이가 [받기]로 지나온 랜드마크 2곳을 도감에 넣습니다.
4. **도착:** "도착했어요! 운전해 줘서 고마워요", 무드등이 초록으로. "랜드마크 3곳을 획득했어요!", "부드럽게 달린 360km만큼 숲이 자랐어요" — 하늘이의 숲에 나무 5그루.
5. **저녁, 집:** 하늘이가 태블릿에서 오늘 심은 나무를 폭포 옆으로 옮기고, 엄마와 함께 봅니다(PT 단계).
6. **다음 날:** 놀이터에서 친구들과 서로의 숲을 보여 주고, 서로의 숲에 놀러 가기로 약속합니다(PT 단계).

### 구조

- 진행 화면(`feature:journey`)과 숲(`feature:forest`)·도감(`feature:atlas`)은 서로를 직접 부르지 않고 여행 사건(`core:trip`)만 구독합니다. 그래서 한 기능만 켠 빌드도 동작합니다.
- 실차 신호와 데모 신호는 같은 인터페이스(`VehicleDataProvider`)로 들어와 스위치 하나로 바꿉니다. Kotlin 2.0, Jetpack Compose, minSdk 28.

## 6. 기대효과 및 발전 가능성

### 타깃 고객

- **1차:** 5~9세 자녀와 장거리 이동하는 가족(초등 연령 인구 약 234만 명, 2025 청소년 통계 참고).
- **2차:** 목적지에서 기다리는 조부모·친척(공유 링크), 아이의 친구 가족(친구 숲).
- **3차:** 친환경차 가족(누적 약 390만 대, 신규 등록의 57.6%). 보너스 새싹으로 친환경차의 의미를 아이에게 보여 줍니다.

### 예상 MAU·Retention (가정)

- **MAU:** 탑재 차량 N대 × 자녀 가구 10% × 설치 15% × 월 1회 사용 40% ≈ **N × 0.6%**. 탑재 100만 대당 약 6,000명.
- **Retention:** 다음 장거리 여행(90일 내) 재사용 40% 목표. 근거: 계정에 쌓이는 숲과 수집(나무·동물·숲 맵·도감 500곳), 여행마다 바뀌는 풍경, 집·친구로 이어지는 숲(PT 단계), 명절·주말처럼 반복되는 이동.

### 발전 방향

- **가족을 하나로:** 차에서 시작한 숲이 집(폰·태블릿)과 친구로 이어져, 차를 타지 않는 날에도 가족이 함께 숲을 돌봅니다.
- **함께 자라는 숲:** 친구 숲은 같은 플랫폼의 차를 타는 가족들을 자연스럽게 잇고, 아이가 친구에게 "우리 숲에 놀러 와!"라고 말하게 합니다.
- **안전 운전 문화:** 보호자의 부드러운 운전이 아이의 기쁨이 되고, 마일리지로 이어집니다(선례: 서울시 에코마일리지 × 현대차·기아 드라이빙 인사이트, 블루링크 안전운전 점수 보험 할인).
- **차량 제어 확장:** 도착 전 공조로 실내 환기·온도 맞추기, 출발 전 "벨트 맸니?" 음성(정차 중·운전자 승인 뒤에만, 창문 열기는 넣지 않음).
- 운전 행동 데이터는 마케팅에 쓰지 않습니다.
